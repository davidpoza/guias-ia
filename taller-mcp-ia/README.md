# Taller práctico: MCP e IA en el día a día

Presentación creada con [Slidev](https://sli.dev/). Cada presentación del
repositorio vive en su propia carpeta; esta es la primera.

## Abrir las diapositivas

Requiere Node.js 22.12 o posterior. Desde esta carpeta:

```powershell
npm install
npm run dev
```

Para generar una versión estática:

```powershell
npm run build
```

## Preparación de las demostraciones

- **draw.io:** Node.js y un cliente MCP compatible con servidores locales.
- **2MD:** distribución completa de 2MD para Windows, conversión y destino
  configurados, MCP local activado y una carpeta de prueba permitida.
- **Chrome DevTools:** Chrome 144 o posterior, `chrome-devtools-mcp` y un
  cliente compatible con visión. Habilitar la depuración remota y aceptar el
  diálogo de conexión de Chrome. Usar MOISES con una cuenta y datos de prueba
  autorizados; no abrir perfiles personales ni pestañas con información sensible.

Los pasos y las rutas de configuración de los clientes MCP pueden variar.
Revisa las diapositivas y la documentación enlazada antes del taller.
